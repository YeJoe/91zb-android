# 直播间付费弹窗绕过修改教程

> 本文档基于特征码搜索定位，适用于版本更新后偏移量变化的情况。

## 一、关键函数信息

| 函数名 | 说明 |
|--------|------|
| `_refreshPullState` | 刷新拉流状态的主函数 |
| `_anon_closure` (在 `_refreshPullState` 内) | 处理拉流状态回调的闭包 |
| `_needPay` | 触发付费弹窗的核心函数 |
| `previewNotifier` | 预览状态通知器 |
| `_anon_closure` (预览回调) | 预览状态回调闭包 |

## 二、修改点 1：跳过 payType == 2 时的付费弹窗

### 2.1 定位方法

#### 方法 A：通过函数名定位（推荐）

1. 在 IDA Pro 中打开 `libapp.so`
2. 按 `Ctrl+F` 搜索函数名：`_refreshPullState`
3. 进入函数后，查找调用 `_needPay` 的位置
4. 在 `_needPay` 调用上方找到 `CMP W1, #2` 指令

#### 方法 B：通过特征码搜索

1. 在 IDA Pro 中按 `Alt+B` 打开字节搜索
2. 搜索以下特征码序列：
   ```
   3F 08 00 71 C1 00 00 54
   ```
   - `3F 08 00 71` = `CMP W1, #2`
   - `C1 00 00 54` = `B.NE +0x18`
3. 找到后，下一条 `BL` 指令就是 `_needPay` 调用

#### 方法 C：通过字符串交叉引用

1. 在 IDA 中搜索字符串：`"refreshPullState >>> call previewNotifier PREVIEW"`
2. 查看该字符串的交叉引用（Xrefs）
3. 向上查找即可找到 `payType == 2` 的判断分支

### 2.2 目标代码结构

```asm
; 加载 payType 字段
LDR     W1, [X0, #7]    ; 读取 payType (field_7)

; 判断 payType == 2
CMP     W1, #2          ; <-- 特征码: 3F 08 00 71
B.NE    loc_skip_pay    ; <-- 特征码: C1 00 00 54 (条件跳转)

; payType == 2 时执行付费逻辑
...
BL      _needPay        ; <-- 调用付费弹窗

loc_skip_pay:
; 跳过付费后的正常流程
```

### 2.3 修改方案

#### 方案 A：将条件分支改为无条件分支（推荐）

- **目标指令**：`B.NE loc_skip_pay`
- **修改位置**：`CMP W1, #2` 之后的那条 `B.NE` 指令
- **原字节**：`C1 00 00 54`（B.NE）
- **新字节**：`06 00 00 14`（B 无条件跳转）

**效果**：无论 payType 是否等于 2，都直接跳过 `_needPay` 调用。

#### 方案 B：NOP 掉调用指令

- **目标指令**：`BL _needPay`
- **修改位置**：`B.NE` 跳转目标之前的 `BL` 指令
- **原字节**：`97 XX XX XX`（BL 指令）
- **新字节**：`1F 20 03 D5`（NOP）

**效果**：即使进入付费分支，也不会实际调用 `_needPay`。

## 三、修改点 2：跳过预览状态检查后的付费弹窗

### 3.1 定位方法

#### 方法 A：通过函数名定位

1. 在 IDA Pro 中搜索函数：`previewNotifier`
2. 查看调用 `previewNotifier` 的闭包函数
3. 在该闭包中查找调用 `_needPay` 的位置

#### 方法 B：通过特征码搜索

1. 在 IDA Pro 中按 `Alt+B` 搜索：
   ```
   3F 10 00 71
   ```
   - `3F 10 00 71` = `CMP W1, #4`（预览状态检查）
2. 找到后，向下查找 `BL _needPay` 调用

#### 方法 C：通过 _needPay 交叉引用

1. 在 IDA 中找到 `_needPay` 函数
2. 按 `Ctrl+X` 查看所有交叉引用
3. 找到第二个调用 `_needPay` 的位置（第一个是 payType==2，第二个是预览状态）

### 3.2 目标代码结构

```asm
; 预览状态检查
CMP     W1, #4          ; <-- 特征码: 3F 10 00 71
B.NE    loc_skip_preview_pay  ; <-- 条件跳转

; 预览状态满足时执行
...
BL      _needPay        ; <-- 调用付费弹窗

loc_skip_preview_pay:
; 跳过付费后的流程
```

### 3.3 修改方案

#### 方案 A：NOP 掉调用指令（最安全）

- **目标指令**：`BL _needPay`
- **修改位置**：预览状态检查闭包中的 `_needPay` 调用
- **原字节**：`97 XX XX XX`（BL 指令）
- **新字节**：`1F 20 03 D5`（NOP）

#### 方案 B：将条件分支改为无条件分支

- **目标指令**：`B.NE loc_skip_preview_pay`
- **修改位置**：`CMP W1, #4` 之后的 `B.NE` 指令
- **原字节**：`XX 00 00 54`（B.NE）
- **新字节**：`XX 00 00 14`（B 无条件跳转）

## 四、通用修改步骤

### 4.1 使用 IDA Pro 定位

1. 打开 `libapp.so`，等待自动分析完成
2. 按 `Shift+F12` 打开字符串窗口
3. 搜索关键词：`"refreshPullState"` 或 `"previewNotifier"`
4. 双击字符串，按 `Ctrl+X` 查看交叉引用
5. 在引用位置附近找到 `CMP` 和 `BL _needPay` 指令
6. 记录目标指令的地址和字节

### 4.2 使用十六进制编辑器修改

1. 用 HxD 或 010 Editor 打开 `libapp.so`
2. 跳转到目标地址（IDA 中的地址 = 文件偏移，因为 ELF 段映射一致）
3. 修改对应字节
4. 保存文件

### 4.3 使用 Python 脚本修改

```python
import struct

so_path = r'path/to/libapp.so'

def find_and_patch(so_path, search_bytes, patch_bytes, description):
    """搜索特征码并修改"""
    with open(so_path, 'r+b') as f:
        data = f.read()
        pos = data.find(bytes.fromhex(search_bytes))
        if pos == -1:
            print(f'[!] 未找到特征码: {description}')
            return False
        
        # 验证找到的位置
        print(f'[+] 找到 {description}  at 0x{pos:x}')
        
        # 应用修改
        f.seek(pos)
        f.write(bytes.fromhex(patch_bytes))
        print(f'[+] 修改完成: {description}')
        return True

# 修改点 1：payType == 2 跳过付费弹窗
# 搜索 CMP W1, #2 后的 B.NE 指令
find_and_patch(
    so_path,
    '3F 08 00 71 C1 00 00 54',  # CMP W1, #2; B.NE
    '3F 08 00 71 06 00 00 14',  # CMP W1, #2; B (无条件)
    '修改点1: payType==2 跳过付费弹窗'
)

# 修改点 2：预览状态跳过付费弹窗
# 搜索 CMP W1, #4 后的 BL _needPay 指令
# 注意：BL 指令的偏移可能变化，需要动态定位
with open(so_path, 'r+b') as f:
    data = f.read()
    # 搜索 CMP W1, #4
    pos = data.find(bytes.fromhex('3F 10 00 71'))
    if pos != -1:
        print(f'[+] 找到预览状态检查 at 0x{pos:x}')
        # 向下搜索 BL 指令（通常在 CMP 后 0x40-0x50 字节范围内）
        for offset in range(pos, pos + 0x60, 4):
            inst = struct.unpack('<I', data[offset:offset+4])[0]
            # BL 指令特征：高 6 位为 100101 (0x94)
            if (inst >> 26) == 0x25:
                print(f'[+] 找到 BL 指令 at 0x{offset:x}')
                f.seek(offset)
                f.write(bytes.fromhex('1F 20 03 D5'))  # NOP
                print(f'[+] 修改点2 完成: 预览状态跳过付费弹窗')
                break
    else:
        print('[!] 未找到预览状态检查')
```

## 五、ARM64 指令参考

| 指令 | 编码格式 | 示例 |
|------|----------|------|
| `CMP Wn, #imm` | `0x71000000 | (imm << 10) | (n << 5) | 0x1F` | `CMP W1, #2` = `71 00 08 3F` |
| `B.NE offset` | `0x54000000 | (imm19 << 5) | 0x01` | `B.NE +0x18` = `C1 00 00 54` |
| `B offset` | `0x14000000 | imm26` | `B +0x18` = `06 00 00 14` |
| `BL target` | `0x94000000 | imm26` | `BL _needPay` = `97 XX XX XX` |
| `NOP` | `0xD503201F` | `NOP` = `1F 20 03 D5` |

## 七、版本更新适配

当版本更新导致偏移量变化时：

1. **重新用 IDA 打开新的 `libapp.so`**
2. **使用本文档中的特征码搜索方法重新定位**
3. **确认找到的代码结构与本文档一致**
4. **应用相同的修改**

关键特征码不会随版本更新而变化：
- `3F 08 00 71` = `CMP W1, #2`（payType 检查）
- `3F 10 00 71` = `CMP W1, #4`（预览状态检查）
- `_needPay` 函数名（Dart AOT 编译后保留）

---

## 八、注意事项

1. 修改前务必备份原始 `libapp.so`
2. 确保修改的是 `.text` 段（可执行代码段）
3. 修改后检查文件完整性（MD5/SHA256）
4. 如果应用有完整性校验，可能需要额外处理
