# 付费直播预览限制破解教程

## 修改目标

让付费直播间预览30秒后可以继续观看，不再弹出付费提示。

---

## 修改文件

`libapp.so`

---

## 修改内容

### 修改点 1：跳过 payType == 2 时的付费弹窗

| 项目 | 内容 |
|------|------|
| 地址 | `0xd4710c` |
| 原指令 | `b.ne 0xd47124` |
| 改为 | `b 0xd47124` |
| 作用 | 当 payType == 2 时跳过 _needPay() 调用 |

### 修改点 2：跳过预览状态检查时的付费弹窗

| 项目 | 内容 |
|------|------|
| 地址 | `0xd49168` |
| 原指令 | `b.ne 0xd491b0` |
| 改为 | `b 0xd491b0` |
| 作用 | 当 previewNotifier.field_27 == 4 时跳过 _needPay() 调用 |

---

## IDA Pro 操作步骤

### 1. 打开文件
```
File -> Open -> 选择 libapp.so
```

### 2. 启动 MCP 插件
```
Edit -> Plugins -> MCP (Ctrl+Alt+M)
```

### 3. 修改第一处
```
按 G 键 -> 输入 0xd4710c -> 回车
Edit -> Patch program -> Assemble
输入: b 0xd47124
点击 OK
```

### 4. 修改第二处
```
按 G 键 -> 输入 0xd49168 -> 回车
Edit -> Patch program -> Assemble
输入: b 0xd491b0
点击 OK
```

### 5. 保存文件
```
Edit -> Patch program -> Apply patches to input file
选择保存路径
```

## 修改效果

| 场景 | 修改前 | 修改后 |
|------|--------|--------|
| 首次进入 | 30秒后弹窗退出 | 继续播放 |
| 再次进入 | 直接弹窗 | 直接播放 |
