# 启动页广告禁用修改教程

> 本文档基于特征码搜索定位，适用于版本更新后偏移量变化的情况。

---

|--------|------|------|

| 方案 | 目标函数 | 风险 | 效果 |
|------|---------|------|------|

| 方案B | `_buildAdView` | 低 | 不显示广告视图 |
| 方案C（推荐） | `AdvDialog::show` | 低 | 广告弹框不显示 |

## 三、修改点 1：禁用广告弹框显示（推荐）

### 3.1 定位方法

#### 方法 A：通过函数名定位（推荐）

1. 在 IDA Pro 中打开 `libapp.so`
2. 按 `Ctrl+F` 搜索函数名：`AdvDialog::show`
3. 进入函数后，找到函数开头

#### 方法 B：通过字符串交叉引用

1. 在 IDA 中按 `Shift+F12` 打开字符串窗口
2. 搜索字符串：`"adv_dialog"` 或包名 `jj_live/dialog/adv/adv_dialog.dart`
3. 查看该字符串的交叉引用（Xrefs）
4. 找到 `AdvDialog::show` 的调用位置

#### 方法 C：通过 pp.txt 定位

在 pp.txt 中搜索以下内容：
```
AdvDialog::show (0x910328)
```

### 3.2 目标代码结构

```asm
; AdvDialog::show 函数开头
0x910328: stp             fp, lr, [SP, #-0x10]!
0x91032c: mov             fp, SP
...
```

### 3.3 修改方案

#### 方案 A：替换为 RET 指令（推荐）

- **目标地址**：0x910328
- **原字节**：`FD 7B BF A9`（STP FP LR, [SP,#-0x10]!）
- **新字节**：`C0 03 5F D6`（RET）

**效果**：函数被调用后立即返回，不执行任何弹框逻辑。

#### 方案 B：通过特征码搜索

1. 在 IDA Pro 中按 `Alt+B` 打开字节搜索
2. 搜索特征码：`FD 7B BF A9 F3 03 00 AA`（STP 后跟 MOV）
3. 找到后，将前 4 字节改为 `C0 03 5F D6`

## 六、通用修改步骤

### 6.1 使用 IDA Pro 定位

1. 打开 `libapp.so`，等待自动分析完成
2. 按 `Ctrl+F` 搜索函数名（如 `AdvDialog::show`）
3. 双击进入函数，确认函数开头
4. 记录地址（如 0x910328）

### 6.2 使用十六进制编辑器修改

1. 用 HxD 或 010 Editor 打开 `libapp.so`
2. 跳转到目标地址
3. 修改对应字节：`C0 03 5F D6`
4. 保存文件

### 6.3 使用 Python 脚本修改

```python
import sys

so_path = r'path/to/libapp.so'

def patch_ret(so_path, address, description):
    """将函数开头替换为 RET 指令"""
    with open(so_path, 'r+b') as f:
        f.seek(address)
        # ARM64 RET 指令: 0xD65F03C0 (小端序: C0 03 5F D6)
        f.write(bytes.fromhex('C0035FD6'))
        print(f'[+] 修改完成: {description} at 0x{address:x}')

# 修改点 1：禁用广告弹框显示
patch_ret(so_path, 0x910328, 'AdvDialog::show')

# 修改点 2：禁用广告视图构建（可选）
patch_ret(so_path, 0x12321e0, '_buildAdView')

# 修改点 3：禁用广告倒计时（风险较高）
patch_ret(so_path, 0xad4f0c, '_startAdTimer')
```

## 七、ARM64 指令参考

| 指令 | 机器码 | 说明 |
|------|--------|------|
| `STP FP, LR, [SP,#-0x10]!` | `FD 7B BF A9` | 函数 prologue |
| `MOV FP, SP` | `F3 03 00 AA` | 设置栈帧 |
| `RET` | `C0 03 5F D6` | 函数返回 |
| `NOP` | `1F 20 03 D5` | 空操作 |

### 常见函数开头模式

Flutter/Dart AOT 编译的函数通常以以下指令开头：

```
FD 7B BF A9    ; STP FP, LR, [SP,#-0x10]!
F3 03 00 AA    ; MOV FP, SP
```

将这两条指令（共8字节）替换为 `RET` 即可让函数直接返回。

## 十、推荐修改方案

### 最安全的方案（推荐）

只修改 `AdvDialog::show` (0x910328)：
- 开屏广告正常显示
- 点击广告不会弹出额外弹框
- 不影响页面跳转和初始化

### 完整禁用方案

1. 修改 `AdvDialog::show` (0x910328) - 禁用弹框
2. 修改 `_buildAdView` (0x12321e0) - 禁用广告视图

**注意**：不建议修改 `_startAdTimer`，可能影响页面跳转逻辑。

## 十一、注意事项

1. **备份原文件** - 修改前务必备份原始 `libapp.so`
2. **架构匹配** - 确保修改的是 arm64-v8a 架构的 so 文件
3. **地址确认** - IDA 显示的地址是虚拟地址
4. **完整性校验** - 部分应用有完整性校验，可能需要额外处理
5. **测试验证** - 修改后充分测试应用功能是否正常
