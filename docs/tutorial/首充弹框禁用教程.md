# 首充图片弹框禁用教程（版本无关）

> 进入直播间约 20 秒后会弹出"首充大礼包"图片弹框。本文介绍如何通过修改 `libapp.so` 禁用它。
>
> **核心原则：Dart AOT 只混淆符号名，不改变指令序列。地址会变，特征码不会变。**

---

## 一、现象与原理

| 项目 | 说明 |
|------|------|
| 弹窗时机 | 进入直播间约 20 秒后 |
| 弹窗内容 | "首充大礼包"图片弹框 |
| 触发页面 | 直播间页面（混淆后为 `EZo__vVa`，即 `audience_live_room_page__State`） |
| 展示函数 | 混淆后为 `sub_F26DC0`（v4.3.3），版本更新后地址会变 |
| 调用链 | 直播间页面闭包 → `sub_F26C90` → `BL sub_F26DC0` |

禁用方式：把 `sub_F26DC0` 的首指令改成 `RET`，函数一进入就返回，弹框逻辑整体跳过。

---

## 二、v4.3.3 直接修改（已知地址）

### 目标代码

```asm
.text:0000000000F26DC0 sub_F26DC0       ; CODE XREF: EZo__vVa::_anon_closure_f26c90+110↑p
.text:0000000000F26DC0                                         ; EZo__vVa::_anon_closure_f26c90+2D0↑p
.text:0000000000F26DC0   STP   X29, X30, [X15,#-0x10]!        ; <== 改成 RET
.text:0000000000F26DC4   MOV   X29, X15
.text:0000000000F26DC8   SUB   X15, X15, #0x40
.text:0000000000F26DCC   STUR  X1, [X29,#-8]
.text:0000000000F26DD0   LDR   X16, [X26,#0x38]
.text:0000000000F26DD4   CMP   X15, X16
.text:0000000000F26DD8   B.LS  loc_F26EA0
.text:0000000000F26DDC   LDR   X0, [X26,#0x68]
.text:0000000000F26DE0   LDR   X0, [X0,#0x27D0]
.text:0000000000F26DE4   CMP   W0, W22
.text:0000000000F26DE8   B.NE  loc_F26E0C
.text:0000000000F26DEC   BL    AllocateyTaStub_fe86dc         ; 首充弹框专用 allocator
...
```

### 修改

| 项目 | 值 |
|------|-----|
| 文件偏移 | `0xF26DC0` |
| 原字节 | `FD 79 BF A9` |
| 新字节 | `C0 03 5F D6`（RET） |

**IDA Pro 操作：**
1. 光标移到 `0xF26DC0`
2. `Edit` → `Patch program` → `Change byte`
3. 输入 `C0 03 5F D6`
4. `Edit` → `Patch program` → `Apply patches to input file`

**十六进制编辑器（HxD / 010 Editor）：**
1. 跳转到偏移 `0xF26DC0`
2. 覆盖 4 字节为 `C0 03 5F D6`
3. 保存

**Python 脚本：**
```python
with open('libapp.so', 'r+b') as f:
    f.seek(0xF26DC0)
    f.write(bytes.fromhex('C0035FD6'))
```

## 三、版本更新后如何重新定位

当拿到新版 `libapp.so`，函数地址变了，按以下步骤重新定位：

### 3.1 方法 A：通过专用子函数 xref 反查（推荐，最稳）

`sub_F26DC0` 内部调用了一个**专用子函数** `sub_F26EA8`（v4.3.3 地址），该子函数**只被 `sub_F26DC0` 一处调用**——这是它唯一的身份标记。

**步骤：**

1. 在 IDA 中按 `Alt+B`，搜索 `sub_F26EA8` 的函数头特征码：
   ```
   FD 79 BF A9 FD 03 0F AA 50 1F 40 F9
   ```
   - `FD 79 BF A9` = `STP X29, X30, [X15,#-0x10]!`
   - `FD 03 0F AA` = `MOV X29, X15`
   - `50 1F 40 F9` = `LDR X16, [X26,#0x38]`

2. 这会命中多个 Dart 函数头。需要进一步筛选：对每个命中处，看函数内部是否调用 `BL sub_58C9F8`（或其他调用 `sub_58C9F8` 的地址）。在新版本中 `sub_58C9F8` 的地址会变，但 `sub_F26EA8` 的指令序列结构不变：
   ```asm
   STP   X29, X30, [X15,#-0x10]!
   MOV   X29, X15
   LDR   X16, [X26,#0x38]
   CMP   X15, X16
   B.LS  ...
   BL    sub_xxxx      ; 调用某个子函数
   CMP   W0, W22
   B.NE  ...
   ```

3. 找到后，光标移到该函数，按 `Ctrl+X` 看 xref。**唯一的调用方**就是新版的首充弹框函数。

4. 进入该调用方，RET 掉首指令。

### 3.2 方法 B：搜索首充弹框函数自身的特征码

`sub_F26DC0` 函数内部有一串独特的指令序列（v4.3.3 实测字节）：

```
40 37 40 F9 00 E8 53 F9 1F 00 16 6B 21 01 00 54
```

- `40 37 40 F9` = `LDR X0, [X26,#0x68]`
- `00 E8 53 F9` = `LDR X0, [X0,#0x27D0]`
- `1F 00 16 6B` = `CMP W0, W22`
- `21 01 00 54` = `B.NE +0x24`

> **注意**：这个序列在 v4.3.3 中命中了 75 个函数（`LDR [X26,#0x68]` + `LDR [X0,#0x27D0]` 的组合很常见），不够唯一。需进一步筛选：
> - 命中后，检查函数内部是否调用了 `AllocateyTaStub_xxxxxxxx`
> - 且被直播间页面闭包（类名含 `vVa`）调用
> - 满足这两个条件的才是首充弹框函数

### 3.3 方法 C：通过 pp.txt 字符串辅助定位

如果手头有 `pp.txt`（Blutter 反编译的字符串表）：

1. 搜索字符串 `img_first_recharge_dialog_bg.png`
2. 找到该字符串的引用闭包地址（如 `pp+0x44578`）
3. 在该闭包附近找 `BL` 调用的目标函数，即为首充弹框

---

## 四、验证

- IDA 重新加载，确认目标地址首字节为 `C0 03 5F D6`（RET）
- 进入直播间等待 20 秒以上，首充图片弹框不再出现
- App 其它功能不受影响

---

## 五、恢复

如需恢复，将 `C0 03 5F D6` 改回 `FD 79 BF A9` 即可。
