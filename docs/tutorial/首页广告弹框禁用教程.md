# 首页广告弹框禁用教程（版本无关）

> 启动 App 进入 HomePage 后弹出的广告弹框（疑似 WebView 调用）。本文介绍如何通过修改 `libapp.so` 禁用它。
>
> **核心原则：Dart AOT 只混淆符号名，不改变指令序列。地址会变，特征码不会变。**

---

## 一、现象与原理

| 项目 | 说明 |
|------|------|
| 弹窗时机 | App 启动后进入首页（HomePage）时 |
| 弹窗内容 | 广告弹框（疑似 WebView） |
| 触发页面 | 首页 HomePage（混淆后为 `_CVa` 类，即 `HomePage` State） |
| 展示函数 | 混淆后为 `sub_FF6D90`（v4.3.3），版本更新后地址会变 |
| 调用链 | HomePage 初始化 → `sub_5E9974`（zTa 构造闭包）→ `BL sub_FF6D90` |

**调用链详情（IDA 反推 + pp.txt 交叉验证）：**

```
sub_FF6D90                        ← 广告弹框展示函数 [目标修改点]
  ↑ BL @ 0x5E99D0
sub_5E9974                        ← 创建 zTa 对象后立即调 sub_FF6D90
  ↑ 内部调用 AllocatezTaStub_ff70b8 → sub_5E9A6C → sub_FF6D90
```

**pp.txt 证据：**
- `sub_5E9974` 紧邻 `AnonymousClosure: (0x5e99ec), of [TSo] zTa`（差值 = 函数大小）
- `zTa` 所属页面内嵌字符串 `"HomePage"`（`pp+0x35240`）
- 同一页面有 `"_needShowStepDialogWhenHomePageReVisible"`（`pp+0x35258`）
- 确认 `_CVa` 就是混淆后的 **HomePage State 类**

禁用方式：把 `sub_FF6D90` 的首指令改成 `RET`，函数一进入就返回，广告弹框逻辑整体跳过。

## 二、v4.3.3 直接修改（已知地址）

### 目标代码

.text:0000000000FF6D90   STP   X29, X30, [X15,#-0x10]!        ; <== 改成 RET
.text:0000000000FF6D94   MOV   X29, X15

### 修改

| 项目 | 值 |
|------|-----|
| 文件偏移 | `0xFF6D90` |
| 原字节 | `FD 79 BF A9` |
| 新字节 | `C0 03 5F D6`（RET） |

**IDA Pro 操作：**
1. 光标移到 `0xFF6D90`
2. `Edit` → `Patch program` → `Change byte`
3. 输入 `C0 03 5F D6`
4. `Edit` → `Patch program` → `Apply patches to input file`

**十六进制编辑器（HxD / 010 Editor）：**
1. 跳转到偏移 `0xFF6D90`
2. 覆盖 4 字节为 `C0 03 5F D6`
3. 保存

**Python 脚本：**
```python
with open('libapp.so', 'r+b') as f:
    f.seek(0xFF6D90)
    f.write(bytes.fromhex('C0035FD6'))
```

## 三、版本更新后如何重新定位

当拿到新版 `libapp.so`，按以下步骤重新定位：

### 3.1 方法 A：通过调用方 `sub_5E9974` 的特征码定位（推荐）

`sub_FF6D90` 的调用方 `sub_5E9974` 有一个独特的特征：内部调用 `AllocatezTaStub_xxxxxxxx` 创建 zTa 对象，然后调用 `sub_FF6D90`。

**步骤：**

1. 在 IDA 中按 `Alt+B`，搜索 `sub_5E9974` 内部独有的指令序列：
   ```
   FD 79 BF A9 FD 03 0F AA EF 81 00 D1
   ```
   - `FD 79 BF A9` = `STP X29, X30, [X15,#-0x10]!`
   - `FD 03 0F AA` = `MOV X29, X15`
   - `EF 81 00 D1` = `SUB X15, X15, #0x20`（栈帧 0x20）

2. 这会命中多个 Dart 函数头。需要进一步筛选：检查函数内部是否调用了 `AllocatezTaStub_xxxxxxxx`（搜索该函数内部是否有对 `AllocatezTaStub` 的 `BL` 调用）。

3. 找到后，光标移到 `AllocatezTaStub` 的 `BL` 指令，按 `Ctrl+X` 看 xref。**zTa 类的构造闭包（即 `sub_5E9974`）** 会出现在 xref 列表中。

4. 进入该函数，在 `AllocatezTaStub` 调用之后，找下一个 `BL` 调用。那个 `BL` 的目标函数就是新版的首屏广告弹框函数。

5. 进入该目标函数，RET 掉首指令。

### 3.2 方法 B：直接搜索 `sub_FF6D90` 自身特征码

在 IDA 中按 `Alt+B`，搜索：
```
FD 03 0F AA EF E1 01 D1 A1 83 1B F8
```
- `FD 03 0F AA` = `MOV X29, X15`
- `EF E1 01 D1` = `SUB X15, X15, #0x78`（栈帧 0x78）
- `A1 83 1B F8` = `STUR X1, [X29,#-0x48]`

该序列会在多个 Dart 函数中命中（所有栈帧 0x78 的函数）。需要筛选：

**筛选规则（按优先级）：**
1. **取第 2 个命中**（v4.3.3 经验规则，命中 3 个，第 2 个是目标）
2. 检查函数内部是否有 `AllocateContextStub_xxxxxxxx` → `MOV X3, X0` → `LDUR X0, [X29,#-0x48]` → `STUR X3, [X29,#-0x58]` → `STUR W0, [X3,#0xF]` 这个特征序列
3. 检查函数内部是否有 `LDR X0, [X0,#0x7A8]`（读取全局缓存字段）

满足以上条件的函数，其首指令改 RET 即可。

### 3.3 方法 C：通过 pp.txt 辅助定位

如果手头有 `pp.txt`：
1. 搜索字符串 `"HomePage"` 的引用闭包
2. 找到 `_CVa` 类的匿名闭包地址
3. 闭包内 `BL` 调用的目标函数即为首屏广告弹框

---

## 四、验证

- IDA 重新加载，确认目标地址首字节为 `C0 03 5F D6`（RET）
- 启动 App 进入首页，广告弹框不再出现
- App 其它功能（HomePage 加载、导航等）不受影响

---

## 五、恢复

如需恢复，将 `C0 03 5F D6` 改回 `FD 79 BF A9` 即可。
