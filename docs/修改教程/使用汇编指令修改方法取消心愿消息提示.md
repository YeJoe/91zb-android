# 使用汇编指令修改方法取消心愿消息提示

## 概述

本方法通过修改汇编指令，将发送心愿消息的关键指令替换为NOP指令，从而阻止心愿消息的显示。这种方法直接在二进制级别修改，无需修改源代码，实现简单且效果彻底。

## 关键指令位置

通过分析，我们找到了两个发送心愿消息的关键指令位置：

1. **心愿下单消息发送位置**：地址 0x10feea4
   - 原始指令：`bl #0xb6f57c` (调用EventBus::emit)
   - 修改为：`nop` (机器码：0xD503201F)

2. **心愿完成消息发送位置**：地址 0x10ff1ac
   - 原始指令：`bl #0xb6f57c` (调用EventBus::emit)
   - 修改为：`nop` (机器码：0xD503201F)

## 修改步骤

### 1. 准备工作

1. 备份原始文件
   ```
   cp e:\Android\duocaiAPK\duocai-out_dir\asm\data_center\manager\room_extend_mgr.dart e:\Android\duocaiAPK\duocai-out_dir\asm\data_center\manager\room_extend_mgr.dart.bak
   ```

2. 准备十六进制编辑工具（如HxD、010 Editor等）

### 2. 定位并修改指令

#### 修改心愿下单消息发送指令

1. 打开 `room_extend_mgr.dart` 文件
2. 跳转到地址偏移量 0x10feea4
3. 将该地址的4字节数据替换为：`1F 20 03 D5` (NOP指令的小端序表示)

#### 修改心愿完成消息发送指令

1. 在同一文件中
2. 跳转到地址偏移量 0x10ff1ac
3. 将该地址的4字节数据替换为：`1F 20 03 D5` (NOP指令的小端序表示)

### 3. 验证修改

1. 使用十六进制编辑器确认修改是否正确
2. 重新打包APK
3. 安装并测试，确认心愿消息不再显示

## 注意事项

1. **备份重要**：修改前务必备份原始文件，以防修改失败导致应用无法运行
2. **地址偏移**：确保修改的地址偏移量准确，错误修改可能导致应用崩溃
3. **重新签名**：修改后需要重新签名APK才能正常安装
4. **版本兼容**：不同版本的APP，指令地址可能不同，需要根据实际情况调整

## 替代方案

如果上述方法不适用，可以考虑以下替代方案：

1. **修改源代码**：直接修改Dart源代码，注释掉EventBus.emit调用
2. **Frida Hook**：使用Frida动态拦截EventBus.emit方法，过滤心愿相关消息
3. **Xposed模块**：开发Xposed模块，在运行时拦截消息发送
