# 禁止主页弹出公告教程

## 概述

本教程将指导您如何修改应用代码，以禁止主页弹出公告的功能。

## 关键代码分析

### 1. 公告弹出逻辑位置

公告弹出逻辑位于 `root_scene.dart` 文件中的 `_popShow` 函数，具体地址为 `0x1428094`。

### 2. 关键判断条件

在 `_popShow` 函数中，系统会检查 `isGgOpen` 的值：

```dart
// 地址 0x1428158
r0 = isGgOpen()
    0x1428158: bl              #0x1428514  ; CacheManager::isGgOpen
```

### 3. isGgOpen 的实现

`isGgOpen` 方法位于 `CacheManager` 类中：

- **Getter 方法地址**: `0x1428514`
- **Setter 方法地址**: `0x10c6c04`

Getter 方法从 `field_b` 字段 Map 中获取 "isGgOpen" 键值，如果为 null 则返回 false。

## 修改方案

### 方案一：修改 isGgOpen 的返回值（推荐）

修改 `CacheManager::isGgOpen` 方法（地址 `0x1428514`），使其始终返回 false：

1. 在 IDA Pro 中导航到地址 `0x1428514`
2. 将原有代码替换为以下汇编代码：

```arm64
.text:0000000001428514 data_center$live_old$model$cache_manager_CacheManager__get_isGgOpen_1428514 
.text:0000000001428514                 STP             X29, X30, [X15,#-0x10]! 
.text:0000000001428518                 MOV             X29, X15 
.text:000000000142851C                 MOV             X0, #0x30      ; 加载立即数0x30到X0 
.text:0000000001428520                 ADD             X0, X26, X0    ; X0 = X26 + 0x30 (false对象地址) 
.text:0000000001428524                 MOV             SP, X29        ; 恢复栈指针 
.text:0000000001428528                 LDP             X29, X30, [X15],#0x10 
.text:000000000142852C                 RET                             ; 返回
```

3. 或者直接使用十六进制值进行修改：`A9BF7BFD 910003FD D2800020 8B0E0140 910003FD A8C17BFD D65F03C0`






## 验证方法

1. 启动修改后的应用
2. 登录账户
3. 检查主页是否不再弹出公告窗口

## 注意事项

1. 修改二进制文件可能会导致应用签名失效，需要重新签名
2. 应用更新后可能需要重新进行此修改
3. 建议在修改前备份原始文件

## 相关文件

- `root_scene.dart`: 包含 `_popShow` 函数，控制公告弹出逻辑
- `cache_manager.dart`: 包含 `isGgOpen` 的 getter 和 setter 方法
- `ida_script/addNames.py`: 包含相关函数地址信息
