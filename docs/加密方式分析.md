# 天美 App 加密方式分析（旧版 blutter 项目 + libapp.so 交叉验证）

> 依据：`tianmei-out_dir`（blutter 解析）+ IDA Pro 反编译 `libapp.so`（Hex-Rays）。
> 复刻实现：`tools/rabbit.py`（Python）/ `webui/lib/rabbit.js`（Node），两边输出一致。
> 运行时校验：`tools/frida_hook_crypto.js`。

## 0. 结论速览

| 项 | 机制 | 代码位置 |
|---|---|---|
| 请求路径 | `base64Url( reverse(xor(reverse(xor(utf8(path),R1)),R2)) + R2 )`，R1=11B、R2=13B 随机 | `HttpRequest::encryptApiPath` 0x111d870 |
| 路径模板 | 客户端发 `{BASE}/go{api_path}`，wire 上是 `{prefix}/{base64url}` | `updateSocketParams` 0x1923e98 |
| 请求体 | protobuf `Request{random,time,path,data}` 整体经 RabbitCipher 加密 | `protoBufHttpRequest` 0xa8162c |
| 加密算法 | RabbitCipher（仿 Rabbit 流密码，key=16B / iv=8B，**非标准 RFC4503**，见 §3） | `rabbit_cipher.dart` |
| 密钥 | `MD5( "jQBUO&2pfS5sC」¥\?AtglXv*w+PcRK8%i" + 小时数 + token )` | `initCipher` 0x192434c |
| IV | 每请求 8 字节随机，base64 后放 **`cipher` 请求头** | `initCipher` 0x192434c |
| 校验 | **`checksum` 头 = md5hex(加密前的 protobuf 明文)** | `HttpRequest::send` 0xab09c8 |
| 鉴权 | `Authorization: Bearer <jwt>`（static field 0x1388） | `updateSocketParams` 0x1923e98 |
| 域名 | 不落盘，`_ApiInfoManager.hosts` 动态下发 + 私有 TCP 隧道 | `api_urls.dart` |

## 1. 请求封装（http_tunnel.dart / http_tunnel_live4.dart）

```
POST {BASE}/go{api_path}                     例: https://api.xxx.com/go/room/list
Headers:
  cipher:       base64(8B 随机 IV)
  checksum:     md5hex(明文 protobuf)
  Content-Type: application/proto
  Accept:       application/proto
  Authorization: Bearer <jwt>        (登录后)
  appId / version / platform / channel / deviceId / timestamp
Body:
  RabbitCipher(key, iv).encrypt(
      Request{ 1:random, 2:time, 3:path="/room/list", 4:data=<业务 protobuf> }
  )
```

- `protoBufHttpRequest`（0xa8162c）先把业务消息包进 `Request`：`random` 为自增计数器
  （static 0x1378），`time` 为 `nowUnixTime()`，`path` 为接口路径，`data` 为业务消息字节。
- 请求发出前，`updateSocketParams`（0x1923e98）把 URL 路径整体替换成混淆路径
  （仅当 `path.startsWith("/go")`，由 `DataCenter._requestCipher` 0x111df44 判定）。
- 响应为 JSON：`{code, msg, data:{body, cipher?, httpStatus}}`，`body` 是加密 protobuf。

## 2. 密钥派生（HttpTunnelLive4::initCipher 0x192434c）

```dart
final hour = DateTime.now().microsecondsSinceEpoch ~/ 1000 ~/ 1000 ~/ 3600;
final raw  = "jQBUO&2pfS5sC」¥\\?AtglXv*w+PcRK8%i" + hour.toString() + token;
final key  = MD5.convert(utf8.encode(raw)).bytes;      // 16B
final iv   = Uint8List(8)..setAll(随机);               // 前 8 字节随机
cipherHeaderIv = base64.encode(iv);                    // -> "cipher" 头
```

- SALT 常量在 `pp+0x18c48`，33 字符 / 36 UTF-8 字节（含 `」` U+300D、`¥` U+00A5、字面 `\`）。
- `token` 为 JWT（`HttpRequest` static 0x1388）；游客态为空串，此时
  `key = MD5(SALT + hour)`。
- **小时数会变**：key 每小时轮换，客户端必须用当前小时重算（`tools/rabbit.py:current_hour_ts`）。

## 3. RabbitCipher 实现细节（flutter_net/rabbit_cipher.dart）

该类实现 `StreamCipher`，结构仿 Rabbit，但**字序、g 函数、状态更新都是自定义**，
不能直接套 RFC 4503 参考实现。已逐函数反编译核对：

### 3.1 字节序助手 `_bytesToUint32`（0x19a5940）
```dart
int _bytesToUint32(Uint8List b) {          // 要求 b.length == 4
  return (b[0] << 24) | (b[1] << 16) | (b[2] << 8) | b[3];   // 大端
}
```

### 3.2 密钥安装 `_setupKey`（0x19a5aa4）
```dart
// key.length 必须 == 16
for (var i = 0; i < 8; i++) {
  final j = (2 * i + 8) & 15;
  X[i] = _bytesToUint32(key.sublist(2 * i, 2 * i + 4));   // 越界回绕取 4B
  C[i] = _bytesToUint32(key.sublist(j, j + 4));
}
```
（i=7 时 `2i+4=18>16`，走回绕分支：`key[14:16] + key[0:2]`）

### 3.3 IV 安装 `_setupIV`（0x19a575c）
```dart
// iv.length 必须 == 8
X[0] ^= _bytesToUint32(iv.sublist(0, 4));
X[1] ^= _bytesToUint32(iv.sublist(4, 8));
for (var i = 0; i < 4; i++) _nextState();
```

### 3.4 状态推进 `_nextState`（0x111c5ac）
```dart
// ① 计数器进位链
var carry = 0;
for (var i = 0; i < 8; i++) {
  final t = (C[i] + X[i] + carry) & 0xFFFFFFFF;
  carry = (t < C[i] || (t == C[i] && carry > 0)) ? 1 : 0;
  C[i] = t;
}
// ② g 函数: s = X[i] + C[i];  g[i] = lo32(s*s) ^ hi32(s*s)
final g = List.filled(8, 0);
for (var i = 0; i < 8; i++) {
  final s = (X[i] + C[i]) & 0xFFFFFFFF;
  final p = s * s;                       // 64bit
  g[i] = (p & 0xFFFFFFFF) ^ (p >> 32);
}
// ③ 状态更新（奇偶不同旋转）
for (var i = 0; i < 8; i++) {
  if (i.isEven) X[i] = g[i] + rotl16(g[(i-1)&7]) + rotl16(g[(i-2)&7]);
  else          X[i] = g[i] + rotl8 (g[(i-1)&7]) +        g[(i-2)&7];
}
```

### 3.5 密钥流 `_generateKeystream`（0x111c394）
```dart
// 每 16 字节推进一次; 每 4 字节换一个 32 位 S; 小端吐字节
for (var i = 0; i < len; i++) {
  if (i % 16 == 0) { _nextState(); S = X[0] ^ X[5]; }
  out[i] = S & 0xFF;
  S >>= 8;
  if (i % 4 == 3) { final j = (i ~/ 4 + 1) & 7; S = X[j] ^ X[(j + 5) & 7]; }
}
```

### 3.6 加/解密 `encryptDecrypt`（0x111c2c4）
```dart
out[i] = input[i] ^ keystream[i];        // 异或, 加解密同一函数
```

## 4. 路径混淆（HttpRequest::encryptApiPath 0x111d870）

```dart
R1 = Uint8List(11) 随机;  R2 = Uint8List(13) 随机;
t = xor(utf8(path), R1);      // t[i] ^= R1[i % 11]
t = t.reversed;
t = xor(t, R2);               // t[i] ^= R2[i % 13]
t = t.reversed;
return base64Url(t + R2);     // R2 附在尾部, 服务端可解
```
- 每次请求 R1/R2 都不同 → 同一接口每次 URL 都不同。
- `updateSocketParams` 最终路径 = `{staticPrefix}/{base64url}`（staticPrefix 见
  `webui/config.json` 的 `pathPrefix`，默认 `/go`，可用抓包校正）。

## 5. 抓包看不到明文的原因 & 复原步骤

1. 路径被替换成 base64url 随机串 → 看不到 `/room/list`。
2. body 是 Rabbit 流加密 → 看不到 JSON。
3. 域名动态下发 → 看不到固定 host。

复原（任选）：
- **Frida**：`tools/frida_hook_crypto.js` 直接 dump `encryptDecrypt` 的
  明文/密文、`encryptApiPath` 的原始路径、`connect()` 的 IP:port。
- **离线复刻**：`tools/live_client.py` / `webui/` 完整实现了 §1–§4，拿到 BASE(+TOKEN)
  即可直接请求。
