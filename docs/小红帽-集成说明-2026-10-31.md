# 小红帽平台集成说明（2026-10-31）

把小红帽（`api.xt2.club`，见 `xhm教程/接口清单_小红帽1.17.1.md`）作为**并列平台**接进本 App，
左侧抽屉一键切换「看天美 / 看小红帽」。

## 用法

1. 启动 App → 首页/关注页顶栏的 **☰ 汉堡**（或小红帽页顶栏的 ☰）打开左侧抽屉；
2. 点 **看小红帽** 切平台；再点 **看天美** 切回。底部三个 tab（首页/关注/设置）两平台共用；
3. 小红帽默认走 **演示数据**（列表/播放/聊天全链路可玩，播放为公开测试 HLS 流）；
4. 要连真实接口：设置 → **小红帽** → 粘贴会话 token（`jwt_token`）→ 关掉「演示模式」→ 刷新列表。
   之后列表、拉流（防盗链 RTMP）、聊天（`wss://…/ws?jwt_token=`）、**接口关注**全部走 `api.xt2.club`。

## 功能清单（小红帽侧）

- **直播间列表（按类别分类）**：`/home` 防御式解析，分类 chips 筛选；
- **关注列表**：本机收藏为底，接口关注打通时服务端同步；
- **主播信息**：播放页顶栏（头像/昵称/人气/分类/序号）+ 卡片星标关注；
- **点击播放**：`/webrtc/v1/pullstream` 取流 → **复用全局 ExoPlayer**（RTMP 直拉，与天美同一套）；
- **底部聊天区 + 发送弹幕**：WebSocket 长连接，防御式解析 chat/gift/sys/enter；输入框常驻，发送乐观回显。

## 关注是怎么实现的（接口关注，不是纯本机）

小红帽与天美的关键差异：**读写同域**。天美的写接口挂在另一套登录态上打不通；
小红帽的 `/relation/follow` 与读接口同在 `api.xt2.club`，token 有效时大概率直接通。
所以策略是：

```
点击 → 本机收藏立刻写入（星标立刻变）
     → 后台打 /relation/follow（候选：/relation/attention、/user/follow）
         ├─ 成功 → toast「已关注（服务端已确认）」
         └─ 失败 → toast「已关注（仅本机）」——如实标注，不假装云端成功
```

demo 模式 / 未填 token 时永远落在「仅本机」分支。

## 边界与已知限制

- 接口文档只给到**路由**，响应体结构是防御式解析（常见字段名都认）；精确字段需 jadx 反编译 `*Api` 接口类；
- demo 播放用 `test-streams.mux.dev` 公开 HLS；真实 RTMP 防盗链约 3 分钟时效，进房实时取；
- 本机无 Android SDK/Gradle/JDK17，**未能本地编译验证**；已做静态一致性检查（跨文件符号/导入/括号）。
  建议在 Android Studio 里 `Build` 一次，若有报错大概率是个别 M3 API 签名差异，属小修。
